# 프로젝트 소개

2인 이상에서 함께 식사 할 수 있게 도와주는 사이트

# 핵심 기능

2인 이상 모일 수 있도록 추천, 그룹, 커뮤니티 기능을 적극 활용해 모임을 구성할 수 있게 도와줍니다

# 페이지들

- 고정 : 메뉴바 (메인홈 돌아가기, 카테고리 -> 세부 : 은정님)
- 전체적인 : 다크모드 (기본 - 화이트)
- 메인 : 처음 접속시 사이트 둘러볼 수 있도록 로그인 스킵!
  -> 검색, 회원가입, 로그인, 추천, 광고, 마이페이지 버튼
  -> 활동, 추천 카테고리 : 나중에 추후
  -> 실시간 검색어? 인기 카테고리? : 은경님
- 회원가입 / 로그인 / 마이페이지
- 모임 게시글 / 후기(리뷰) : 모이는 페이지 따로 후기 페이지 따로
- 실시간 채팅 : 모임 게시글 안에서 해당 모임 채팅방 들어가게끔
- 그룹 생성 / 설정 : 로그인된 사람들

## 메인화면

- 게시글 : 이미지, 제목, 태그들
- 카테고리
- 사용자 : 사용자 이미지, 닉네임

## 회원가입

- 아이디, 비번 / 이메일 / 이름 / 성별 / 닉네임 / 전화번호 / 주소 / 생년월일 / 카테고리 (처음에 어떤 관심이 있는지 확인)

## 개인 프로필 (마이) 페이지

- 성별 / 닉네임 / 주소(동) / 나이 / 프로필사진 / 자기소개 / 카테고리
- 모달 : 관심사 수정 / 아이디, 비번 수정 / 회원탈퇴 / 프로필 수정

## 안내사항(공지) 페이지

- 공지사항 제목, 공지사항 설명

## 모임 게시글 상세 페이지

- 모임 제목, 모임 설명(목적), 태그들, 카테고리, 모임 위치, 지도

# 엔터티(테이블) 정리

- 사용자 관련 : 아이디, 이메일, 이름, 성별, 비밀번호, 닉네임, 전화번호, 주소, 생년월일, 탈퇴여부
- 모임 게시글 : 이미지, 모임 제목, 모임 설명(목적), 모임 위치, 지도
- 카테고리 : 카테고리 이름
- 태그

- 공지사항 게시글 : 공지사항 제목, 공지사항 설명 (우선순위 낮게)

- 음식 관련 : 음식 이름, 대표 사진, 음식 설명, 태그, 생성일, 수정일 -> 이건 배제

> 상의할 내용 : 좋아요 (사용자, 생성일), 댓글 (사용자, 음식, 생성일, 댓글내용)
